# PWA (หน้าเว็บที่ติดตั้งเป็นแอปบนมือถือได้) — วิธีติดตั้ง

โฟลเดอร์นี้คือหน้าเว็บทั้งหมดของแอป (ไม่มี build step, ไม่มี framework — เปิดได้ตรงๆ)
ต้อง host ขึ้นเว็บก่อนถึงจะ "เพิ่มไปยังหน้าจอโฮม" ได้ (มือถือไม่ยอมติดตั้ง PWA จากไฟล์ในเครื่องเฉยๆ)

ก่อนใช้งาน ต้อง [deploy backend Apps Script ก่อน](../apps_script/README.md) แล้วเอา URL ที่ได้มาใส่ตอนเปิดแอปครั้งแรก

## วิธี host ฟรี (เลือกอันใดอันหนึ่ง)

### ตัวเลือก A: Netlify Drop (ง่ายสุด ไม่ต้องมี GitHub)

1. เปิด https://app.netlify.com/drop
2. ลากทั้งโฟลเดอร์ `pwa/` ไปวางในหน้านั้น
3. ได้ลิงก์ทันที เช่น `https://xxxxx.netlify.app`
4. ข้อเสีย: ถ้าจะอัปเดตแอปทีหลัง ต้องลากโฟลเดอร์ไปวางซ้ำทุกครั้ง (ไม่มีการเชื่อมกับโค้ดอัตโนมัติ)

### ตัวเลือก B: GitHub Pages หรือ Vercel/Netlify ผ่าน Git (ถ้าจะอัปเดตบ่อย)

1. สร้าง repo บน GitHub แล้ว push โฟลเดอร์ `pwa/` (เป็น root ของ repo หรือใช้ path `/pwa` ก็ได้)
2. เชื่อม repo กับ Vercel หรือ Netlify (import project) หรือเปิด GitHub Pages ใน repo settings
3. ทุกครั้งที่ push โค้ดใหม่ เว็บจะอัปเดตอัตโนมัติ

## เพิ่มไปยังหน้าจอโฮม (หลังเปิดลิงก์ที่ host ไว้)

**iPhone/iPad (Safari):** เปิดลิงก์ → กดปุ่ม Share (ไอคอนสี่เหลี่ยมมีลูกศรชี้ขึ้น) → เลื่อนหา **"เพิ่มไปยังหน้าจอโฮม"** (Add to Home Screen) → กด "เพิ่ม"

**Android (Chrome):** เปิดลิงก์ → กดเมนู 3 จุดมุมขวาบน → **"ติดตั้งแอป"** หรือ **"เพิ่มไปยังหน้าจอโฮม"** → ยืนยัน

จะได้ไอคอนแอปจริงบนหน้าจอโฮม (รูปบ้าน พื้นสีน้ำเงิน) เปิดแล้วเต็มจอ ไม่มีแถบ address bar ของเบราว์เซอร์

## ตั้งค่าครั้งแรกในแอป

เปิดแอปขึ้นมาครั้งแรกจะเห็นข้อมูลตัวอย่างเหมือนเดิม (ลองกดเล่นได้) ให้ไปที่ **⚙️ ตั้งค่า → เชื่อมข้อมูลออนไลน์**
วางลิงก์ Apps Script Web App ที่ได้จากขั้นตอน [deploy backend](../apps_script/README.md) แล้ววาง — ระบบจะจำไว้ในเครื่องนี้ ไม่ต้องใส่ซ้ำอีก
จากนั้นกด **"เริ่มใช้จริง"** เพื่อล้างข้อมูลตัวอย่างแล้วเริ่มจดของจริง

**ให้แม่กับคุณเห็นข้อมูลเดียวกัน:** ติดตั้งแอปในมือถือ/ไอแพดของทั้งสองคน แล้ววางลิงก์ Apps Script **เดียวกัน** ในหน้าตั้งค่าของทั้งสองเครื่อง

## ทดสอบก่อน deploy จริง (ในเครื่อง)

```bash
cd pwa
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000 ในเบราว์เซอร์ (service worker/manifest ทำงานได้บน localhost แม้ไม่ใช่ https
แต่การ "เพิ่มไปยังหน้าจอโฮม" ต้องรอ host จริงก่อน — มือถือไม่ยอมติดตั้งจาก localhost)
